## Weekly Summary

### Week 1 - HTML Fundamentals
Implemented a basic HTML webpage structure with a title, heading, and paragraph. It also linked an external CSS file (style.css) for styling and placed the content inside a .box container.


### Week 2 - Semantic & Multimedia
Implemented a semantic HTML5 webpage using header, navigation, main content, multimedia section, figure/image, video, and footer elements. It also includes internal navigation links and an external CSS file for styling.

### Week 3 - CSS Basics
Implemented a CSS-styled webpage with a header, navigation menu, content sections, and a contact form. The page is connected to an external style.css file for layout, colors, spacing, and overall design.

### Week 4 - JavaScript Basics and DOM Manipulation
Implemented an interactive JavaScript webpage with a theme toggle, dynamic heading, functional to-do list, contact form validation, and modal message display. JavaScript is connected using script.js with defer for interactive functionality.

### Week 5 - Javascript Functions and Bootstrap
Implemented a Bootstrap responsive website with a navigation bar, image carousel, About section, and three service cards. It uses Bootstrap grid layouts, buttons, responsive images, and styled content to create an organized and interactive webpage.


### Week 6 - API & Client Storage
Implemented a Bootstrap-based laboratory website with a responsive navigation bar, user preferences for theme and language, Local Storage for saving the user's name, Weather and GitHub API features, and a location map feature.


### Week 7 - MiniFullStackStarter
Created a simple full-stack web application using HTML, CSS, Bootstrap, JavaScript, Express.js, and MongoDB. The project allows users to be added and displayed through an API and is deployed online using Render.
